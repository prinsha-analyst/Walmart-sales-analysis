# Walmart Sales Data Analysis

## Project Overview

This project analyzes Walmart retail sales data to generate meaningful business insights. The analysis includes data cleaning using Python and answering business-related questions using SQL.

The objective of this project is to understand sales performance, customer behavior, and product trends across different branches and cities.

---

## Dataset

The dataset contains transactional sales records from Walmart stores. It includes information such as:

* Branch
* City
* Product category
* Quantity sold
* Payment method
* Sales amount
* Profit margin
* Date and time of transaction
* Customer rating

Dataset file: `walmart_clean_data.csv`

---

## Data Cleaning

Data cleaning was performed using Python and Pandas in Jupyter Notebook.

Steps performed:

* Removed missing or inconsistent values
* Converted date and time columns to proper format
* Standardized column names
* Prepared the dataset for analysis

File: `Walmart_clean_data.ipynb`

---

## SQL Business Analysis

SQL was used to answer important business questions from the dataset.
A total of **26 business queries** were written to analyze the data.

Some of the key analyses include:

* Payment method transaction analysis
* Highest rated category in each branch
* Busiest sales day for each branch
* Revenue distribution across cities
* Profit generated by each category
* Top performing cities by revenue
* Branch revenue ranking
* Monthly revenue analysis
* Revenue trends over time

File: `walmart.sql`
