
# Walmart Sales Data Analysis

## Project Overview

This project analyzes Walmart retail sales data using Python and SQL to generate business insights.

## Step 1: Data Cleaning

Data cleaning was performed using Python (Pandas) in Jupyter Notebook.

Tasks performed:

* Removed missing values
* Converted date and time columns
* Standardized column names
* Exported cleaned dataset

File: `data_cleaning.ipynb`

## Step 2: SQL Business Analysis

After cleaning the dataset, SQL was used to answer business questions.

Total queries: **26**

Key analysis:

* Payment method transaction analysis
* Highest rated category in each branch
* Busiest sales day
* Revenue trend analysis
* Profit analysis by category
* Branch revenue ranking

File: `walmart_sql_queries.sql`

## Tools Used

* Python (Pandas)
* SQL (MySQL)
* Jupyter Notebook
* GitHub
